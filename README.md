# Pixacity

A minimalist cel-shaded 3D **Returning Soon** page built with React, Vite, Tailwind CSS, and Three.js.

## Features

- Interactive 3D cel-shaded emblem with custom 3-band toon shading, rim lighting, and angle-weighted outlines
- Multi-layered cel-shaded sky and clouds with consistent screen-space outlines and atmospheric sun glow
- Responsive layout across mobile portrait, mobile landscape, tablet, and desktop viewports

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
